# Changelog

All notable changes to Roombook are listed here, newest first.

## 0.2.0

### New

- Book a meeting room for a time slot. Bookings run on a 15-minute grid, between 08:00 and 18:00 UTC, for up to four hours.
- See a room's bookings and its free time for any day, so you can pick a slot before you book.
- List bookings for a room, for a day, or both.
- A booking that clashes with one already in the room is refused, with a message that says so.

## 0.1.0

### New

- Browse the meeting rooms, with each room's floor and how many people it seats.
- Search rooms by name.
- Open a single room to see its details.
